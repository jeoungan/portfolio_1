AI 에이전트 이식 웹 크롤링 · PDF 학습(RAG) 경량화 최적화 Google · Naver 검색 API

2026년 고려대학교 생물심리 연구실 인턴으로 참여하며, 상용 로봇 Rumi를 심리학부 안내용 프로토타입으로 바꾸는 작업을 맡았습니다. 학교 홈페이지 자료로 안내 정보를 구성하고, 로봇 화면에는 학부 영상을 연결했습니다.

대화형 AI를 연결하는 과정에서는 기기 사양 때문에 오류가 반복됐습니다. 기술 서적을 찾아가며 동작을 확인한 뒤, 특정 음성·키워드에 반응하도록 범위를 줄이고 검색 API로 정보를 보완했습니다. 이 경험을 통해 필요한 기능과 실제 작동 조건을 함께 보는 법을 배웠습니다.
